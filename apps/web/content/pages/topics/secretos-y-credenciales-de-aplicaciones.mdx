Toda aplicación necesita datos de configuración y, muchas veces, credenciales: la contraseña de una base de datos, una clave de API, un token. Dónde los guardas y cómo los entregas a la aplicación marca la diferencia entre un sistema seguro y uno con secretos expuestos en el código.

## Qué problema resuelve

Escribir las credenciales directamente en el código fuente o en archivos de configuración las deja al alcance de cualquiera que pueda inspeccionar la aplicación o sus componentes. Además, cambiar una credencial obliga a modificar y volver a desplegar la aplicación. Guardar los secretos en un servicio dedicado permite entregarlos solo cuando se necesitan, controlar quién puede leerlos y renovarlos sin tocar el código.

## Conceptos clave

### AWS Secrets Manager

AWS Secrets Manager te ayuda a administrar, recuperar y rotar credenciales de bases de datos, credenciales de aplicaciones, tokens de OAuth, claves de API y otros secretos durante todo su ciclo de vida. Muchos servicios de AWS guardan y usan secretos en Secrets Manager.

- **Sin credenciales incrustadas**: sustituyes las credenciales escritas en el código por una llamada en tiempo de ejecución a Secrets Manager que las recupera de forma dinámica cuando hacen falta. Así evitas que se vean comprometidas por quien pueda inspeccionar tu aplicación.
- **Rotación automática**: puedes configurar una programación para reemplazar secretos de largo plazo por otros de corto plazo, lo que reduce de forma significativa el riesgo de que se vean comprometidos. Como las credenciales ya no se guardan con la aplicación, rotarlas no obliga a actualizar ni a volver a desplegar las aplicaciones cliente.
- **Dos formas de rotar**: la rotación administrada, en la que el servicio configura y gestiona la rotación sin usar una función de Lambda, y la rotación mediante una función de AWS Lambda para otros tipos de secretos. Rotar significa actualizar la credencial tanto en el secreto como en la base de datos o el servicio.
- **Cifrado y control**: los secretos se cifran con claves de AWS KMS, con la clave administrada `aws/secretsmanager` o con una propia. El acceso se controla con IAM, y AWS CloudTrail registra las llamadas a la API.
- Pagas solo por lo que usas, sin cargos mínimos ni de configuración.

### AWS Systems Manager Parameter Store

Parameter Store es un almacén centralizado de datos de configuración, en forma de valores con nombre llamados parámetros. Sirve para guardar, organizar y recuperar de forma segura datos de configuración a escala, y para que las aplicaciones los lean en tiempo de ejecución sin valores escritos en el código. Admite tres tipos de parámetro:

- **String**: texto sin formato, como nombres de entornos, URL de puntos de enlace o identificadores de recursos.
- **StringList**: una lista de valores separados por comas.
- **SecureString**: valores que requieren cifrado, que Parameter Store cifra con AWS KMS.

Para secretos como credenciales de bases de datos, claves de API o tokens, AWS recomienda Secrets Manager, que ofrece controles de seguridad específicos como la rotación automática y la replicación entre regiones.

### Elegir dónde guardar cada dato

| Necesidad                                                                                                   | Servicio            |
| ----------------------------------------------------------------------------------------------------------- | ------------------- |
| Configuración estática, como identificadores de AMI, variables de entorno, URL de puntos de enlace          | Parameter Store     |
| Configuración que cambia con frecuencia, banderas de funciones, despliegues sin tiempo de inactividad       | AWS AppConfig       |
| Credenciales y datos cifrados que requieren rotación automática, acceso entre cuentas o auditoría detallada | AWS Secrets Manager |

### Otros tipos de secreto

Hay secretos para los que existe un servicio específico:

- **Credenciales de AWS**: IAM. Las cargas de trabajo deben usar roles, que entregan credenciales temporales, y no claves de largo plazo.
- **Claves de cifrado**: AWS KMS.
- **Claves SSH**: Amazon EC2 Instance Connect.
- **Claves privadas y certificados**: AWS Certificate Manager.
