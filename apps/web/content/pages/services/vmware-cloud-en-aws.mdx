VMware Cloud on AWS es una oferta de nube integrada, desarrollada en conjunto por AWS y VMware, que permite migrar y ampliar entornos locales basados en VMware vSphere a la nube de AWS. Se ejecuta sobre infraestructura bare metal de Amazon EC2 y la entregan, venden y respaldan VMware y sus socios.

## Qué problema resuelve

Muchas empresas tienen sus servidores virtualizados con vSphere y su operación construida alrededor de VMware. Cambiar de plataforma al migrar puede obligar a cambiar también herramientas y procesos. VMware Cloud on AWS permite llevar esas cargas a AWS manteniendo la plataforma de virtualización de VMware, y acceder desde ellas a los servicios de AWS.

## Conceptos clave

### Casos de uso

AWS describe VMware Cloud on AWS como una opción pensada para organizaciones de infraestructura y operaciones de TI que quieren:

- **Migrar** a la nube pública cargas de trabajo locales basadas en vSphere.
- **Consolidar y ampliar** la capacidad de sus centros de datos.
- **Optimizar, simplificar y modernizar** sus soluciones de recuperación ante desastres.

### Relación con la estrategia de migración

Llevar servidores de una plataforma local a la versión en la nube de esa misma plataforma corresponde a la estrategia de migración de reubicación (relocate). Esta estrategia no requiere comprar hardware nuevo, reescribir aplicaciones ni cambiar la operación existente, y es la forma más rápida de migrar porque no cambia la arquitectura de la aplicación.

### VMware en tus instalaciones

AWS Outposts tiene una variante, VMware Cloud on AWS Outposts, que permite usar en tus instalaciones el mismo plano de control y las mismas API de VMware con las que ya administras tu infraestructura. La variante nativa de Outposts, en cambio, usa las API y el plano de control de AWS.
