AWS Snow Family es la familia de dispositivos físicos de AWS para mover datos sin usar internet y para procesar datos en lugares con poca o ninguna conectividad. Su miembro actual es **AWS Snowball Edge**, un dispositivo resistente con almacenamiento y capacidad de cómputo propios. Importante: según la documentación de AWS, Snowball Edge, y con él toda la familia Snow, **ya no está disponible para clientes nuevos**; los clientes existentes pueden seguir usándolo.

## Qué problema resuelve

Cuando hay que llevar a AWS una gran cantidad de datos y la red es lenta o poco fiable, transferirlos por internet puede tardar demasiado. Snowball Edge resuelve esto transportando los datos físicamente: AWS envía el dispositivo, copias los datos en local y lo devuelves por mensajería para que se carguen en Amazon S3, a velocidades mayores que las de internet. También permite procesar datos y ejecutar cargas de cómputo en el borde, cerca de donde se generan.

## Conceptos clave

### Trabajos de importación y exportación

En un trabajo de **importación**, AWS te envía un dispositivo vacío, copias en él los datos de tus sistemas locales y lo devuelves. En uno de **exportación**, AWS copia los datos de S3 en el dispositivo y te lo envía. La transferencia admite NFS y la API de Amazon S3 mediante el adaptador de S3.

### Configuraciones del dispositivo

- **Storage Optimized**: centrado en la capacidad de almacenamiento para mover datos.
- **Compute Optimized**: centrado en el cómputo en el borde, con instancias que se ejecutan en el dispositivo a partir de AMI y puntos de enlace compatibles con Amazon S3 y Amazon EC2.

Los dispositivos se pueden agrupar en clústeres para almacenamiento y cómputo local con mayor durabilidad.

### Seguridad

El cifrado es obligatorio: los datos están protegidos en reposo y durante el transporte físico.

### Alternativas que recomienda AWS

Para clientes nuevos, AWS propone:

- **Transferencia en línea**: AWS DataSync, que puede combinarse con AWS Direct Connect para superar las limitaciones de ancho de banda.
- **Transferencia física**: AWS Data Transfer Terminal, ubicaciones donde llevas tus propios dispositivos para cargar los datos en AWS, o soluciones de socios.
- **Cómputo en el borde**: AWS Outposts.
