AWS Lake Formation es el servicio para gobernar, proteger y compartir de forma centralizada los datos que usan el análisis y el aprendizaje automático. Administra el control de acceso de grano fino sobre los datos del lago en Amazon S3 y sobre sus metadatos en el AWS Glue Data Catalog, y ayuda a llevar al lago datos de bases de datos existentes. El tema «Lagos de datos» explica cómo se construye y protege un lago completo; aquí ves el servicio en sí.

## Qué problema resuelve

Cuando varios equipos analizan los mismos datos en S3 con servicios distintos, controlar quién ve qué con políticas de bucket y de IAM se vuelve complejo: esas políticas trabajan con buckets y prefijos, no con tablas, columnas ni filas. Lake Formation ofrece su propio modelo de permisos, parecido al de una base de datos relacional: concedes o revocas permisos sobre bases de datos, tablas y columnas del catálogo, y esos permisos se aplican en todos los servicios de análisis integrados. Así sustituye las combinaciones complejas de políticas de bucket y de IAM.

## Conceptos clave

- **Permisos de grano fino**: se aplican a nivel de columna, fila y celda en servicios como Amazon Athena, Amazon Quick, Amazon Redshift Spectrum, Amazon EMR y AWS Glue. Dos analistas pueden consultar la misma tabla y obtener solo los datos que tienen permitidos.
- **Entrega de credenciales temporales (credential vending)**: cuando un usuario consulta una tabla registrada, el Data Catalog comprueba sus permisos en Lake Formation. Si está autorizado, Lake Formation da al motor de análisis un acceso temporal a S3, y el motor filtra columnas, filas o celdas antes de devolver el resultado.
- **Registro de ubicaciones**: para que Lake Formation gestione el acceso a los datos, registras en él la ubicación de S3 de las tablas.
- **Control basado en etiquetas (LF-Tags)**: asignas etiquetas clave-valor, como `department=sales`, a bases de datos, tablas o columnas, y concedes permisos sobre las etiquetas. Es el método recomendado cuando hay muchos objetos en el catálogo. Las LF-Tags no son lo mismo que las etiquetas de IAM.
- **Compartir entre cuentas**: puedes compartir bases de datos y tablas con otras cuentas, organizaciones o entidades de IAM de otra cuenta. Lake Formation usa AWS Resource Access Manager para hacerlo.
- **Modo de acceso híbrido**: permite activar los permisos de Lake Formation de forma gradual, para ciertos usuarios o tablas, sin interrumpir las políticas de IAM que usan otras cargas de trabajo.
- **Ingesta**: puede importar datos y su esquema desde MySQL, PostgreSQL, SQL Server, MariaDB y Oracle en Amazon RDS o Amazon EC2, con cargas masivas o incrementales.
