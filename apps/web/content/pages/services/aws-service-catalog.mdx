AWS Service Catalog permite a una organización crear y administrar catálogos de servicios de TI aprobados para usar en AWS. Esos servicios pueden ir desde imágenes de máquinas virtuales, servidores, software o bases de datos hasta arquitecturas completas de aplicaciones de varios niveles.

## Qué problema resuelve

Si cada equipo crea sus propios recursos con acceso directo a los servicios, es difícil lograr un gobierno consistente y cumplir los requisitos de la empresa, por ejemplo dónde se lanza cada recurso o qué tipo de instancia usa. Service Catalog centraliza los servicios de TI que se despliegan con frecuencia: los administradores definen productos aprobados, con sus restricciones y etiquetas, y los usuarios finales los despliegan por su cuenta, en autoservicio, sin acceso directo a los servicios subyacentes.

## Conceptos clave

- **Producto**: un servicio de TI que quieres ofrecer para desplegar en AWS. Se crea a partir de una plantilla de AWS CloudFormation que define los recursos, sus relaciones y los parámetros que el usuario puede ajustar. También admite configuraciones de Terraform.
- **Producto aprovisionado**: cada vez que un usuario lanza un producto se crea una pila de CloudFormation, que se aprovisiona, actualiza y termina como una sola unidad.
- **Portafolio**: una colección de productos con información de configuración. Creas portafolios para cada tipo de usuario y das acceso a cada uno mediante usuarios, grupos y roles de IAM. Puedes compartirlos con otras cuentas de AWS.
- **Restricciones**: limitan cómo se lanza un producto, por ejemplo dónde se puede lanzar o qué tipo de instancia se puede usar.
- **Restricción de lanzamiento**: indica el rol de IAM que Service Catalog asume al lanzar, actualizar o terminar un producto. Así el usuario final solo necesita los permisos mínimos para ese producto, y no permisos sobre CloudFormation y todos los servicios que el producto usa.
- **Versiones**: al publicar una versión nueva de un producto, queda disponible para todos los usuarios que tienen acceso a él, que pueden actualizar sus productos ya lanzados.
