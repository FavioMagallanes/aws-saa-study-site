AWS Trusted Advisor inspecciona tu entorno de AWS y te hace recomendaciones cuando encuentra oportunidades para ahorrar dinero, mejorar la disponibilidad y el rendimiento de los sistemas o cerrar brechas de seguridad. Sus comprobaciones se basan en prácticas recomendadas aprendidas al atender a cientos de miles de clientes de AWS.

## Qué problema resuelve

Con el tiempo, una cuenta acumula configuraciones arriesgadas o costosas que nadie revisa: instantáneas públicas, grupos de seguridad con puertos abiertos, recursos infrautilizados o cuotas de servicio a punto de agotarse. Revisarlas a mano en cada cuenta no es práctico. Trusted Advisor ejecuta comprobaciones automáticas sobre tus recursos y te muestra qué conviene corregir y qué acción se recomienda.

## Conceptos clave

- **Categorías de comprobaciones**: optimización de costos, rendimiento, seguridad, tolerancia a fallos, límites de servicio y excelencia operativa.
- **Depende del plan de soporte**: con el plan Basic Support accedes desde la consola a todas las comprobaciones de límites de servicio y a algunas de seguridad y tolerancia a fallos, como instantáneas públicas de Amazon EBS y Amazon RDS, permisos de buckets de Amazon S3, MFA en la cuenta raíz o grupos de seguridad con puertos sin restringir. Los planes superiores dan acceso a todas las comprobaciones y a la API de Trusted Advisor.
- **Actualización de resultados**: con el plan Basic las comprobaciones de seguridad no se actualizan solas y debes refrescarlas manualmente.
- **Vista organizativa**: con AWS Organizations, todas las funciones habilitadas y un plan de soporte adecuado en la cuenta de administración, creas informes que agregan los resultados de todas las cuentas miembro.
- **Supervisión con eventos**: puedes vigilar el estado de las comprobaciones con Amazon EventBridge para reaccionar cuando cambian.
- **Otras fuentes**: muestra comprobaciones basadas en AWS Config y controles de AWS Security Hub CSPM, y puede incorporar recomendaciones de AWS Compute Optimizer.
