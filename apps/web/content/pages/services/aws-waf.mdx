AWS WAF es un firewall de aplicaciones web que supervisa las solicitudes HTTP(S) que llegan a tus recursos protegidos y decide, según tus reglas, si se atienden, se bloquean con un código HTTP 403 (Prohibido) o reciben una respuesta personalizada.

## Qué problema resuelve

Muchos ataques llegan como solicitudes web aparentemente normales: inyección de SQL, secuencias de comandos entre sitios (XSS), bots o una avalancha de peticiones desde unas pocas direcciones. AWS WAF los filtra antes de que alcancen tu aplicación, con reglas propias o administradas. Los tipos de ataque se explican en el tema «Amenazas externas: DDoS e inyección de código».

## Conceptos clave

### Qué puede proteger

Se asocia, entre otros, a una distribución de Amazon CloudFront, una API REST de Amazon API Gateway, un Application Load Balancer, una API GraphQL de AWS AppSync, un grupo de usuarios de Amazon Cognito, un servicio de AWS App Runner o AWS Amplify. Para aplicaciones en contenedores de Amazon ECS, pones delante un Application Load Balancer con WAF habilitado.

### Lista de control de acceso web y reglas

- **Lista de control de acceso web (web ACL)**: el recurso central. Agrupa las reglas, se asocia a uno o varios recursos y tiene una acción predeterminada para las solicitudes que ninguna regla permitió o bloqueó. En la consola nueva aparece como paquete de protección (protection pack).
- **Reglas**: cada una tiene un criterio de inspección y una acción: permitir, bloquear, contar o comprobar con CAPTCHA o un desafío que el cliente es una persona o un navegador estándar. Los criterios pueden ser, por ejemplo, la IP de origen o los valores de la cadena de consulta.
- **Grupos de reglas**: conjuntos reutilizables, propios o administrados.
- **Unidades de capacidad (WCU)**: AWS WAF las usa para calcular y controlar los recursos que necesitan las reglas, los grupos de reglas y las listas.

### Reglas útiles para el examen

- **Grupos de reglas administrados**: reglas listas para usar que AWS o vendedores de AWS Marketplace escriben y mantienen. Algunos cubren vulnerabilidades comunes, como varias del OWASP Top 10, y otros tipos concretos de aplicación. La mayoría de los de AWS no tienen costo adicional, salvo Bot Control y los de prevención de fraude.
- **Reglas basadas en frecuencia**: cuentan las solicitudes agrupadas según tus criterios y limitan las que llegan demasiado rápido, útiles frente a inundaciones de solicitudes.
- **Reglas de inyección de SQL y XSS**: inspeccionan componentes de la solicitud en busca de código malicioso.
