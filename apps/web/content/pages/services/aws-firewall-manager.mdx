AWS Firewall Manager centraliza la administración de protecciones de red y de aplicación en varias cuentas y recursos de una organización. Configuras la protección una sola vez y el servicio la aplica de forma automática en tus cuentas y recursos, incluso cuando agregas cuentas y recursos nuevos.

## Qué problema resuelve

Con muchas cuentas, configurar AWS WAF, AWS Shield Advanced, grupos de seguridad o firewalls de red cuenta por cuenta es lento y deja huecos: basta un recurso nuevo sin proteger. Firewall Manager te permite definir una línea base y aplicarla a toda la organización, a todos los recursos de un tipo (por ejemplo, todas las distribuciones de Amazon CloudFront) o a los que tengan ciertas etiquetas. Es especialmente útil cuando quieres proteger toda la organización y no solo unas pocas cuentas, o cuando agregas recursos con frecuencia.

## Conceptos clave

### Requisitos

- Funciona con AWS Organizations: una cuenta de administrador de Firewall Manager gestiona todas las políticas de seguridad de la organización.
- Necesita AWS Config habilitado en cada cuenta miembro, incluida la de administrador, y en cada región con recursos que quieras proteger.
- Los cargos corresponden a los servicios subyacentes, como AWS WAF y AWS Config.

### Tipos de política

Cada política es de un solo tipo, y puedes crear varias:

- **AWS WAF**: define grupos de reglas que se ejecutan primero y al final en la lista de control de acceso web; el dueño de cada cuenta puede añadir sus reglas entre ambos.
- **Shield Advanced**: aplica sus protecciones a los tipos de recurso que elijas en toda la organización, y puede suscribir a Shield Advanced a todas las cuentas miembro.
- **Grupos de seguridad y ACL de red de Amazon VPC**: impone un conjunto base de reglas en toda la organización.
- **AWS Network Firewall** y **Route 53 Resolver DNS Firewall**: aplican esas protecciones a las VPC de la organización.
- **Firewalls de terceros**, contratados mediante AWS Marketplace.

### Cumplimiento y corrección

En cada política defines el alcance, con etiquetas si quieres, y eliges si solo ver las cuentas y recursos que no cumplen o corregirlos de forma automática. Cuando una cuenta nueva se une a la organización, Firewall Manager le aplica las políticas que correspondan. También ofrece supervisión centralizada de ataques DDoS en la organización.
