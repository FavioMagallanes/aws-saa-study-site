Amazon AppFlow es un servicio de integración totalmente administrado para intercambiar datos de forma segura entre aplicaciones de software como servicio (SaaS), como Salesforce, Slack o Zendesk, y servicios de AWS como Amazon S3 o Amazon Redshift. Defines un flujo con un origen y un destino, y AppFlow mueve los datos sin que escribas código.

## Qué problema resuelve

Llevar datos de una aplicación SaaS a AWS suele exigir escribir y mantener código que llame a la API del proveedor, programe las extracciones y gestione los errores. AppFlow sustituye ese código propio por flujos configurables que puedes crear en minutos, ejecutar cuando quieras o con una programación, y supervisar para saber qué datos se movieron, adónde y cuándo.

## Conceptos clave

### Flujos y desencadenadores

Un flujo transfiere datos entre un origen y un destino. El desencadenador decide cuándo se ejecuta:

- **Bajo demanda**: lo ejecutas manualmente cada vez que necesitas transferir datos.
- **Por evento**: AppFlow lo ejecuta cuando ocurre un evento de cambio en la aplicación SaaS de origen. Solo está disponible para las aplicaciones que ofrecen esos eventos.
- **Programado**: se ejecuta de forma periódica. Puedes elegir una transferencia **completa**, que copia todos los registros en cada ejecución, o **incremental**, que copia solo los registros nuevos o modificados desde la última ejecución correcta.

### Seguridad y transferencia privada

AppFlow cifra los datos en reposo y en tránsito. Con algunas aplicaciones SaaS integradas con AWS PrivateLink, como Salesforce o Snowflake, puedes crear **flujos privados**: los datos viajan por la infraestructura de AWS en lugar de por internet, y AppFlow crea por ti la configuración del servicio de punto de enlace de VPC. La cuenta SaaS debe tener habilitado el acceso por PrivateLink.

### Preparar los datos para el análisis

- Puedes catalogar en el AWS Glue Data Catalog los datos que transfieres a Amazon S3, para que los servicios de análisis y machine learning los encuentren con facilidad.
- Puedes organizar los datos transferidos en particiones y archivos para mejorar el rendimiento de las consultas.
- Si un origen no está integrado, puedes crear un conector personalizado con los SDK de AppFlow para APIs privadas, sistemas locales u otras nubes.
