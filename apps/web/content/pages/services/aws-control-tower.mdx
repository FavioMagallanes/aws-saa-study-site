AWS Control Tower es la forma más sencilla de configurar y gobernar un entorno de AWS con varias cuentas siguiendo prácticas recomendadas. Orquesta otros servicios, como AWS Organizations, AWS Service Catalog y AWS IAM Identity Center, para crear una zona de aterrizaje y mantenerla gobernada con controles.

## Qué problema resuelve

Cuando una empresa pasa de unas pocas cuentas a muchas, montar cada una a mano con sus registros, permisos y políticas lleva tiempo y produce diferencias entre cuentas. Control Tower crea el entorno de varias cuentas por ti, estandariza las cuentas nuevas y aplica controles que evitan la deriva, es decir, que las cuentas se alejen de las prácticas recomendadas. Cómo encajan Organizations, las SCP y Control Tower en una estrategia de seguridad para varias cuentas se explica en el tema "Estrategia de varias cuentas: Organizations, SCP y Control Tower".

## Conceptos clave

### Zona de aterrizaje

Una zona de aterrizaje (landing zone) es un entorno de varias cuentas bien diseñado y basado en prácticas de seguridad y cumplimiento. Contiene todas tus unidades organizativas (OU), cuentas, usuarios y demás recursos sujetos a normas de cumplimiento, y escala a empresas de cualquier tamaño.

### Controles

Un control (a veces llamado guardrail) es una regla de alto nivel, expresada en lenguaje sencillo, que da gobernanza continua. Cada control aplica una sola regla.

- **Preventivos**: impiden que una acción ocurra; el intento se deniega y se registra en CloudTrail. Se implementan con políticas de control de servicios (SCP) y políticas de control de recursos (RCP).
- **De detección**: detectan situaciones concretas, por ejemplo un volumen de EBS sin cifrar asociado a una instancia. Se implementan con reglas de AWS Config.
- **Proactivos**: comprueban los recursos antes de aprovisionarlos con plantillas de CloudFormation y no los crean si no cumplen. Se implementan con hooks de CloudFormation.

Según su guía, los controles son obligatorios (siempre aplicados y no se pueden cambiar), muy recomendados u opcionales.

### Account Factory y panel

- **Account Factory**: plantilla de cuenta configurable que estandariza el aprovisionamiento de cuentas nuevas con configuraciones preaprobadas. Se basa en productos aprovisionados de AWS Service Catalog y aplica de forma automática los controles y las políticas a cada cuenta.
- **Panel**: muestra a los administradores centrales las cuentas aprovisionadas, los controles activos y los recursos no conformes por cuenta y OU.
- **Cuentas existentes**: puedes registrar una organización existente e inscribir sus cuentas para gobernarlas con Control Tower.
