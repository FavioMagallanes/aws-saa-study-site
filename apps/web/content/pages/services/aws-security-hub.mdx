AWS Security Hub reúne en un solo lugar las señales de seguridad de tu entorno de AWS para que veas y priorices los problemas más importantes. La documentación actual distingue dos partes: AWS Security Hub CSPM, que evalúa tu entorno frente a estándares y prácticas recomendadas de seguridad, y Security Hub, una solución unificada que correlaciona los hallazgos de CSPM y de otros servicios para priorizar los riesgos activos.

## Qué problema resuelve

Cada servicio de seguridad produce sus propios hallazgos: GuardDuty detecta amenazas, Amazon Inspector vulnerabilidades y Macie datos sensibles. Revisarlos por separado, en varias cuentas y regiones, hace difícil saber qué atender primero. Security Hub los consolida, comprueba de forma continua tu configuración frente a estándares de seguridad y te ayuda a automatizar la respuesta.

## Conceptos clave

### Estándares y controles (Security Hub CSPM)

- **Estándares**: incluye el estándar AWS Foundational Security Best Practices (FSBP), desarrollado por AWS, y marcos externos como CIS, PCI DSS y NIST.
- **Controles**: cada estándar tiene varios controles, cada uno una práctica recomendada. Security Hub CSPM los comprueba y genera hallazgos de control que muestran tu grado de cumplimiento, y con los resultados calcula puntuaciones de seguridad.
- **Depende de AWS Config**: usa reglas de AWS Config para la mayoría de los controles. Si usas solo Security Hub CSPM, debes habilitar AWS Config y el registro de recursos en cada cuenta y región donde lo actives.

### Hallazgos consolidados

- Recibe hallazgos de Amazon GuardDuty, Amazon Inspector, Amazon Macie y productos de terceros compatibles.
- Security Hub CSPM normaliza los hallazgos con el formato AWS Security Finding Format (ASFF), así que no tienes que manejar formatos distintos según el origen.
- Puedes agregar los hallazgos de varias regiones y administrar varias cuentas desde una cuenta de administrador.
- Security Hub CSPM solo procesa hallazgos generados después de habilitarlo, y en la región donde lo habilitaste.

### Automatización

- **Reglas de automatización**: modifican o suprimen hallazgos según los criterios que definas.
- **Amazon EventBridge**: dispara respuestas automáticas a hallazgos concretos.

### Lo que añade Security Hub

Correlaciona los hallazgos para detectar exposiciones de los recursos y muestra un gráfico de rutas de ataque. Además, identifica roles, usuarios, claves de acceso y permisos de IAM que no se han usado en los últimos 90 días, y puede proponer una política más restringida para aplicar el mínimo privilegio.
