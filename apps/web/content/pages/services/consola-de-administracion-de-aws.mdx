La consola de administración de AWS (AWS Management Console) es una aplicación web que reúne y da acceso centralizado a las consolas de cada servicio de AWS. Su página de inicio se llama AWS Console Home y desde ahí administras tus aplicaciones y llegas al resto de las consolas.

## Qué problema resuelve

Cada servicio de AWS tiene su propia consola. Sin un punto de entrada común tendrías que recordar dónde está cada una, configurar por separado el idioma o la región y cambiar de herramienta para ejecutar un comando. La consola unifica la navegación, la búsqueda, las notificaciones y la configuración en un solo lugar, desde el navegador.

## Conceptos clave

- **Navegación unificada**: accedes a las consolas visitadas hace poco, a tu lista de favoritos, a la configuración y a las notificaciones de AWS User Notifications.
- **Búsqueda unificada**: buscas servicios, funciones y productos de AWS Marketplace.
- **Configuración unificada**: personalizas aspectos como el idioma y la región predeterminada.
- **AWS Console Home**: se personaliza con widgets, como los servicios visitados recientemente o AWS Health. Con myApplications supervisas el costo, el estado, la postura de seguridad y el rendimiento de tus aplicaciones.
- **AWS CloudShell**: un shell en el navegador, ya autenticado con las credenciales con las que entraste a la consola, para ejecutar comandos de la AWS CLI sin instalar nada.
- **Inicio de sesión**: entras como usuario raíz, como usuario de IAM, como usuario de IAM Identity Center o con una identidad federada. El usuario raíz tiene acceso completo a todos los servicios y recursos de la cuenta, y AWS recomienda no usarlo en las tareas diarias.
- **Acceso privado (Console Private Access)**: limita el uso de la consola a un conjunto de cuentas de AWS conocidas cuando el tráfico sale de tu red. Se implementa con puntos de enlace de VPC de AWS PrivateLink, de modo que el tráfico del navegador no necesita salir a internet, y admite redes locales conectadas por AWS Direct Connect o AWS Site-to-Site VPN.
