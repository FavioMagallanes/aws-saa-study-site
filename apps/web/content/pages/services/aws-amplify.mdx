AWS Amplify sirve para crear aplicaciones web de pila completa en AWS, con datos, autenticación, almacenamiento y alojamiento del frontend. Su parte de alojamiento, Amplify Hosting, ofrece un flujo de trabajo basado en Git para publicar aplicaciones web sin servidor con despliegue continuo en la red global de entrega de contenido (CDN) de AWS.

## Qué problema resuelve

Publicar un frontend moderno implica configurar compilaciones, almacenamiento, una CDN, certificados, dominios y entornos para cada rama. Amplify Hosting reúne todo eso: conectas un repositorio de Git y cada cambio se compila y se despliega automáticamente. Para el backend, Amplify Gen 2 ofrece una experiencia basada en código TypeScript para definirlo y conectarlo a la aplicación.

## Conceptos clave

### Qué puedes alojar

- **Frameworks SSR**, como Next.js o Nuxt. En Next.js, Amplify Hosting compute administra por completo la renderización del lado del servidor.
- **Aplicaciones de una sola página (SPA)**, como React, Angular o Vue.js.
- **Generadores de sitios estáticos**, como Gatsby, Hugo o Jekyll.

### Funciones de Amplify Hosting

- **Ramas de funciones**: entornos de producción y de pruebas conectando nuevas ramas, y vistas previas de las solicitudes de extracción (pull requests).
- **Despliegues atómicos**: la aplicación solo se actualiza cuando todo el despliegue termina, así no hay ventanas de mantenimiento ni archivos a medio subir.
- **Dominios personalizados**, con un certificado administrado que Amplify aprovisiona o uno propio.
- **Ramas protegidas con contraseña**, redirecciones y reescrituras, y pruebas de extremo a extremo.

### Despliegue sin Git

Puedes desplegar manualmente arrastrando una carpeta comprimida, o desde un bucket de Amazon S3 o una URL pública. Los despliegues manuales no admiten aplicaciones SSR.
