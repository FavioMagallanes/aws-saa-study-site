Amazon Polly es un servicio en la nube que convierte texto en voz realista. Admite varios idiomas y una variedad de voces, y sirve para crear aplicaciones habladas que mejoran la participación y la accesibilidad.

## Qué problema resuelve

Grabar locuciones para cada texto de una aplicación no escala: el contenido cambia y hay que cubrir varios idiomas. Polly genera el audio a partir del texto bajo demanda. Casos habituales: lectores de noticias, juegos, plataformas de aprendizaje en línea, aplicaciones de accesibilidad para personas con discapacidad visual y dispositivos de Internet de las cosas (IoT).

## Conceptos clave

- **Cómo funciona**: eliges un motor de voz, llamas al método de síntesis con el texto y el formato de salida, y Polly devuelve un flujo de audio casi en tiempo real.
- **Síntesis asíncrona para textos largos**: con `StartSpeechSynthesisTask`, Polly encola la solicitud, la procesa en segundo plano, sube el audio a un bucket de Amazon S3 y, si lo configuras, avisa en un tema de Amazon SNS cuando termina.
- **Motores de voz**: generativo, de formato largo, neuronal y estándar. El motor neuronal incluye además un estilo de presentador de noticias.
- **No traduce**: la voz sintetizada está en el mismo idioma que el texto de entrada. Para otro idioma, traduces primero con Amazon Translate.
- **SSML**: con el lenguaje de marcado de síntesis de voz (Speech Synthesis Markup Language) controlas la pronunciación, el volumen, el tono y la velocidad, o añades pausas, énfasis o susurros.
- **Léxicos**: personalizan la pronunciación de palabras, por ejemplo para que un acrónimo se lea completo. Se guardan en una región y se aplican al sintetizar.
- **Formatos de salida**: MP3 u Ogg Vorbis para aplicaciones web y móviles, PCM para dispositivos de AWS IoT y telefonía, y Mu-law o A-law para telefonía.
- **Costo**: pagas solo por el texto que sintetizas y puedes guardar en caché y reproducir el audio generado sin costo adicional.
- Está certificado para cargas reguladas por HIPAA y PCI DSS.
