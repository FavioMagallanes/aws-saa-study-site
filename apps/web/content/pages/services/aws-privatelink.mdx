AWS PrivateLink es una tecnología de alta disponibilidad y escalable para conectar de forma privada tu VPC con servicios y recursos como si estuvieran dentro de ella. Los clientes de tus subredes privadas llegan a esos destinos con direcciones IP privadas, sin puerta de enlace de internet, dispositivo NAT, dirección IP pública, Direct Connect ni Site-to-Site VPN.

## Qué problema resuelve

Los puntos de enlace predeterminados de los servicios de AWS son públicos, así que una instancia de una subred privada necesita una puerta de enlace NAT y una de internet para llegar a ellos. Si tus requisitos de seguridad no lo permiten, o si quieres consumir un servicio de otra cuenta sin interconectar redes completas, PrivateLink expone solo el servicio concreto dentro de tu VPC. Así controlas exactamente qué puntos de enlace, servicios y recursos son alcanzables. Los tipos de punto de enlace y su comparación con los de puerta de enlace se tratan en el tema "Puntos de enlace de VPC y PrivateLink".

## Conceptos clave

### Proveedores y consumidores

- **Proveedor de servicios**: es el propietario del servicio, ya sea AWS, un socio de AWS u otra cuenta. Crea un **servicio de punto de enlace** delante de un balanceador de carga, que recibe las solicitudes y las envía al servicio. De forma predeterminada no está disponible para nadie: debes dar permiso a principales concretos.
- **Consumidor**: crea un punto de enlace de VPC indicando el servicio, el recurso o la red de servicios a la que quiere llegar. Puede acceder desde su VPC o desde su red local.

### Tipos de punto de enlace

- **De interfaz**: envía tráfico TCP o UDP a un servicio de punto de enlace, como un servicio de AWS, el de otra cuenta o un producto SaaS de un socio. Se resuelve por DNS.
- **De Gateway Load Balancer**: envía tráfico a una flota de dispositivos virtuales usando tablas de enrutamiento.
- **De recurso**: accede directamente a un recurso compartido de otra VPC, como una base de datos, sin balanceador de carga.
- Los puntos de enlace de **puerta de enlace** para Amazon S3 y DynamoDB **no** usan PrivateLink.

### Interfaces de red y políticas

- Por cada subred que elijas se crea una interfaz de red del punto de enlace, que es la entrada del tráfico hacia el servicio.
- Una **política de punto de enlace** es una política de recursos de IAM que decide qué principales pueden usar el punto de enlace. La predeterminada lo permite todo.
- **Costo**: pagas por cada hora que un punto de enlace de interfaz está aprovisionado en cada zona de disponibilidad y por cada GB de datos procesados.
