Amazon Managed Grafana es un servicio de visualización de datos totalmente administrado basado en Grafana, una herramienta de código abierto muy extendida. Sirve para consultar, correlacionar y visualizar métricas, registros y trazas operativas que vienen de varias fuentes, sin operar tus propios servidores de Grafana.

## Qué problema resuelve

Montar Grafana por tu cuenta implica aprovisionar servidores, configurarlos, escalarlos y mantenerlos, además de resolver la autenticación de los usuarios y el acceso a cada fuente de datos. Amazon Managed Grafana se encarga del aprovisionamiento, la configuración, el escalado y el mantenimiento, y añade funciones de seguridad para cumplir requisitos de gobierno corporativo, como inicio de sesión único, control de acceso a los datos e informes de auditoría.

## Conceptos clave

- **Espacios de trabajo (workspaces)**: son servidores de Grafana lógicamente aislados. Dentro de cada uno creas paneles y visualizaciones sin construir ni desplegar hardware.
- **Fuentes de datos**: son los almacenes que consultas desde Grafana. Se integra con fuentes de AWS que recogen datos operativos, como Amazon CloudWatch, Amazon OpenSearch Service, AWS X-Ray, Amazon Timestream y Amazon Managed Service para Prometheus, y también con muchas fuentes de código abierto, de terceros y de otras nubes.
- **Varias fuentes en un panel**: puedes combinar datos de varias fuentes en un mismo panel de control.
- **Permisos para fuentes de AWS**: incluye una función de aprovisionamiento de permisos para agregar servicios de AWS compatibles como fuentes de datos.
- **Autenticación**: los usuarios inician sesión mediante proveedores de identidad compatibles con SAML 2.0 o mediante AWS IAM Identity Center.
- **Precio por usuario**: se cobra por usuario activo en cada espacio de trabajo.
