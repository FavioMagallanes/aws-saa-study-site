Amazon Textract añade detección y análisis de texto de documentos a tus aplicaciones. Detecta texto impreso y manuscrito y extrae datos estructurados, como formularios y tablas, de archivos de imagen y PDF, sin necesidad de experiencia en aprendizaje automático.

## Qué problema resuelve

Muchos procesos de negocio dependen de documentos escaneados: informes financieros, historiales médicos, formularios fiscales, facturas o documentos de identidad. Transcribirlos a mano es lento, y un reconocimiento de texto simple pierde la estructura (qué valor corresponde a qué campo o celda). Textract extrae el texto y sus relaciones para incorporarlos a flujos de trabajo, índices de búsqueda o aplicaciones de procesamiento de lenguaje natural. Pagas solo por los documentos que analizas.

## Conceptos clave

### Operaciones según el tipo de documento

- **Detección de texto**: palabras y líneas de texto impreso o manuscrito.
- **Análisis de documentos**: texto, formularios y tablas. Con **Queries** preguntas por un dato concreto del documento, y con **Custom Queries** entrenas un adaptador con tus documentos para personalizar las respuestas.
- **Facturas y recibos**: la API `AnalyzeExpense`.
- **Documentos de identidad**: la API `AnalyzeID`, para licencias de conducir y pasaportes emitidos por el gobierno de Estados Unidos.
- **Préstamos hipotecarios**: el flujo Analyze Lending clasifica las páginas y las envía a la operación de análisis adecuada.

### Síncrono frente a asíncrono

- **Síncrono**: procesa documentos de una página con respuestas casi en tiempo real, para aplicaciones donde la latencia es crítica.
- **Asíncrono**: procesa documentos de varias páginas en PDF o TIFF guardados en Amazon S3. Inicias con una operación `Start`, el estado de finalización se publica en un tema de Amazon SNS, lo recibes con una cola de Amazon SQS o una función de AWS Lambda y obtienes los resultados con la operación `Get`.

Las operaciones de la API tienen cuotas; algunas se pueden aumentar desde Service Quotas.
